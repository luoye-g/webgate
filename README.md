# webgate

一个简单的 Go 语言示例项目 / A simple Go language example project

## 项目内容 / Project Contents

这个仓库包含：/ This repository contains:

- **main.go**: 一个简单的 Go 程序，输出 "hello world" / A simple Go program that prints "hello world"
- **LICENSE**: Apache 2.0 开源许可证 / Apache 2.0 open source license
- **go.mod**: Go 模块配置文件 / Go module configuration file

## 如何运行 / How to Run

确保已安装 Go 1.18 或更高版本 / Make sure you have Go 1.18 or higher installed

```bash
# 运行程序 / Run the program
go run main.go

# 或者先编译再运行 / Or compile and then run
go build -o webgate
./webgate
```

## 输出 / Output

```
hello world
```
